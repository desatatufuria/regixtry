# tui-v2-redesign

Objective: migrate the TUI to the Bubble Tea v2 line (bubbletea, bubbles, lipgloss), then implement the redesign (easy repository grants, longer token lifetime, mouse), with nothing merged into develop until the user says it is finished.
Branch: `feature/tui-v2-redesign` (tracker, cut from develop a485b56). Delivery strategy: ask-on-risk (chain strategy is asked only when publishing). Test runner: `GOTOOLCHAIN=go1.27.4 go test ./... -count=1`, plus `go build ./...`, `go vet ./...`, `gofmt -l .`.

## Specs

- S1 Migration. User: "debemos de ir a las ultimas versiones de bubbletea". Scope: Bubble Tea, bubbles and lipgloss move to the v2 line (`charm.land/...`). Acceptance: build, vet, gofmt (empty) and the full test suite are green on Go 1.27.4; migration slices change no behavior, the existing tests are the safety net.
- S2 Branch policy. User: "lanza una rama tracker donde vamos a trabajar la migración de lo qeu tenemos sin mergear en develop hasta que terminesmos". Acceptance: all work lands on `feature/tui-v2-redesign`; develop receives nothing until the user declares it finished.
- S3 Redesign. User: "actualmente es un poco mala la experiencia de usuario", "quiero que revises cómo hacer que mejore esa experiencia", "tenemos un nuevo artefacto genreado con el nuevo diseño". Reference design: https://claude.ai/artifact/KxBpWQsgQdsVE5kXhzTr3D (screens: Admin workspace, Grant repository access, Auth tokens). Assumption: the mockup is a UX and flow direction, not a pixel spec; the implementation keeps the existing Nord theme (`internal/tui/admin_theme.go`), fits the 150x24 minimum the TUI enforces (`internal/tui/viewport.go:44`).
- S4 Grants. User: "debe de poder hacerse facil agregar a un usuario un repostirio". Acceptance: one screen to pick a user or robot, pick repositories (filter, multi-select, a not-yet-pushed name allowed), pick a role, review and apply; a partial failure reports the result per repository.
- S5 Token lifetime. User: "también quiero poder darle más tiempo de vida a un token de auth creo que actualmente está en torno a los 60 días". Verified fact: the current default and hard ceiling are 30 days, not 60 (`internal/domain/auth/token.go:15`, `internal/app/auth/service.go:377`). OPEN DECISION: the new maximum, which the user has not chosen. Acceptance: lifetime presets with the exact expiry date visible before creating; the server ceiling raised to the chosen value.
- S6 Mouse. User: "me gustaría poder usar el ratón com he visto que se hace con un montón de tuis", "si njo fuera posible con bubble deberiamos de pensar en otra biblioteca". Verified: Bubble Tea supports mouse (v1.3.10 `MouseMsg`; v2 `MouseClickMsg`, `MouseWheelMsg`, `View.MouseMode`), so the library stays. Acceptance: the wheel scrolls lists and tables; clicks work on the new screens' controls. Assumption: a toggle for mouse capture exists so the one-time token secret can still be selected and copied.
- S7 Order. User: "deberiamos de plantear el nuevo diseño en la transición?", accepted with "sí, dale" to: migration first, redesign after. Acceptance: migration slices land before any redesign slice; the redesign is planned in this same document.
- S8 Orchestration. User: "los cambios que estas haciendo, no los deben de hacer agentes? tu solo debes orquestar". Acceptance: from here on every code change is written by a delegated agent; the parent orchestrates, checks each diff against the allowed edit surfaces, spot-checks one reported command and owns git. T3 was written inline before this instruction, under the routing text then in force; it stays, verified.
